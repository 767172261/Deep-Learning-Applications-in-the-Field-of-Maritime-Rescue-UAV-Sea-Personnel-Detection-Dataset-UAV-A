
### 🛰️ **tinyperson 航拍小目标人物检测数据集**

| **项目** | **详细信息** |
|----------|--------------|
| **数据集名称** | inyperson（Infrared or Aerial Tiny Person Detection Dataset） |
| **数据类型** | 航拍图像（无人机视角） |
| **图像总数** | **1,610 张**（官方提供） |
| **图像格式** | `.jpg` 或 `.png`（RGB 或 多光谱，具体依原始数据而定） |
| **标注格式** | YOLO 格式 `.txt` 文档（每图对应一个 `.txt` 文件）<br>`class_id center_x center_y width height`（归一化坐标） |
| **任务类型** | 小目标检测（Tiny Object Detection） |
| **适用模型** | YOLOv5/v8/v10 等系列目标检测模型 |
| **是否已划分** | ✅ 是（官方划分，无需手动分割） |
| **是否含背景图** | ✅ 是（无标注目标的纯背景图像，已用空 `.txt` 补充） |
| **配置文件** | ✅ 提供 `data.yaml`，可直接用于训练 |

---

### 📊 **数据集划分详情**

| 子集 | 正常标签图片 | 密集标签图片 | 背景图片（无目标） | 总计 |
|------|----------------|----------------|----------------------|--------|
| **训练集 (train)** | 717 张 | 48 张 | 29 张 | **794 张** |
| **测试集 (test)**  | 781 张 | 30 张 | 5 张  | **816 张** |
| **总计**           | **1,498 张** | **78 张** | **34 张** | **1,610 张** |

> ✅ 所有图像均配有对应的 `.txt` 标注文件，背景图像为**空文件**，符合 YOLO 训练规范。

---

### 🧩 **类别定义（nc: 2）**

| 类别 ID | 类别名称（英文） | 类别名称（中文） | 描述 |
|--------|------------------|------------------|------|
| 0 | `earth_person` | 陆地人物 | 出现在陆地场景中的人物（如沙滩、草地、道路、山区等），通常为小目标（<32x32像素） |
| 1 | `sea_person`   | 水上/海中人物 | 出现在水域环境中的人物（如落水者、游泳者、海上救援目标），用于搜救任务 |

> 🔍 **特点**：  
> - 目标极小（tiny person），挑战性强  
> - 场景复杂（光照变化、遮挡、低对比度）  
> - 适用于**无人机搜救、海上救援、边境巡检**等应用

### 📁 推荐数据组织结构

```bash
inyperson_dataset/
├── images/
│   ├── train/          # 794 张训练图像
│   └── test/           # 816 张测试图像
├── labels/
│   ├── train/          # 794 个 .txt 标签（含空文件）
│   └── test/           # 816 个 .txt 标签（含空文件）
├── data.yaml           # YOLO 配置文件
└── README.md
```

---

### 🧾 **data.yaml 配置文件模板**

```yaml
# data.yaml
train: ./inyperson_dataset/images/train
val: ./inyperson_dataset/images/test  # 注意：官方称为 test，但可作 val 使用

# 类别数量
nc: 2

# 类别名称
names:
  - earth_person
  - sea_person
```

> ⚠️ 注意：YOLO 中 `val` 指验证集，此处将 `test` 作为验证集使用。

### 🎯 **主要应用领域**

| 应用场景 | 说明 |
|----------|------|
| **无人机搜救系统** | 在山区、森林、海上搜索失踪人员，自动识别微小人物目标 |
| **海上救援辅助** | 检测落水者（`sea_person`），提升救援效率 |
| **边境与海岸线巡检** | 防止非法越境、偷渡行为 |
| **灾害应急响应** | 地震、洪水后快速扫描幸存者 |
| **智慧安防监控** | 大范围区域异常人员入侵检测 |

### ✅ **数据集优势**

| 优势 | 说明 |
|------|------|
| ✅ **真实航拍数据** | 来自无人机拍摄，视角真实，具备工程价值 |
| ✅ **小目标挑战性强** | 人物尺寸小，适合测试模型对微小物体的检测能力 |
| ✅ **类别区分明确** | 区分陆地与水域人物，支持多场景建模 |
| ✅ **背景图完整处理** | 空 `.txt` 文件已补充，符合 YOLO 训练要求 |
| ✅ **开箱即用** | 提供 `data.yaml`，可直接开始训练 |

---

### 🚀 推荐训练方案（YOLOv8）

```bash
yolo train \
    model=yolov8s.pt \
    data=inyperson_dataset/data.yaml \
    epochs=150 \
    imgsz=640 \
    batch=16 \
    name=inyperson_yolo \
    device=0
```

> 🔍 建议：
> - 使用 `mosaic=True` 增强小目标学习
> - 提高 `imgsz` 至 `640` 或 `1280` 以提升小目标检测精度
> - 使用 `--augment` 启用数据增强

---

### 📈 评估重点指标

| 指标 | 说明 |
|------|------|
| **mAP@0.5** | 主要评估指标，衡量整体检测精度 |
| **Recall** | 检测出的正样本比例，尤其关注漏检率 |
| **Precision** | 避免误报，特别是在背景复杂区域 |
| **Inference Speed (FPS)** | 是否满足无人机实时处理需求 |
